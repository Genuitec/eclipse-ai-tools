# Changelog

## 1.0.0

*November 2026*

{/* TODO: Set the release date. */}

First production release:

- **Live Review:** review uncommitted changes inline in your text editor, and
  undo individual changes.
- **Inline Compare:** switch Eclipse's Compare Editor between side-by-side and
  inline views.
- **Time Machine:** explore past file versions on a timeline without changing
  your editor buffer or the file on disk.
- Light and dark theme support for the navigator, change widgets, and Time Machine.
- The floating navigator's **⋮** menu is now available in the Compare Editor and
  in the Time Machine viewer.
- New **Inline Diff** preference page that links to all Inline Diff settings.
