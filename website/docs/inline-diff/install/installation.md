# Installation

Install Inline Diff from Eclipse Marketplace, then restart Eclipse.

## Prerequisites

- An Eclipse IDE or Eclipse-based product running on Java 17 or later.
- Windows 11 or 10, macOS, or Linux.

No AI coding assistant is required. Inline Diff reviews changes made by you,
your teammates, or an AI coding agent.

## Install

1. Open **Help > Eclipse Marketplace**.
2. Search for **Inline Diff** and click **Install**.
3. Follow the prompts, review and accept the license, and finish installation.
4. Restart Eclipse when prompted.

:::note Screenshot needed: Installation
Show Eclipse Marketplace search results for **Inline Diff**, with the product
name, icon, and **Install** button visible.
Suggested filename: **marketplace-install.png**.
:::

After restarting, look for **Show Changes** in the status bar. Open a file and
try [Live Review](../live-review.md).

:::tip Already installed ChangeReview?
Inline Diff is installed automatically with ChangeReview 1.0 Early Access 2 and
later. See [ChangeReview installation](/changereview/installation).
:::

## Updating

Open **Help > Check for Updates**, select an available Inline Diff update,
and follow the prompts. Restart Eclipse to complete the update.

## Uninstalling

Open **Help > About Eclipse IDE > Installation Details**. Select Inline Diff
on the **Installed Software** tab, click **Uninstall**, and follow the prompts.
Restart Eclipse when prompted.

If ChangeReview is installed, uninstall it first, because it requires Inline Diff.

Need assistance? See [Getting Help](../getting-help.md).
