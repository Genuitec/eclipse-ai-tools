# Changelog

## 1.0 Early Access 2

*November 2026*

{/* TODO: Set the release date. */}

- **Built on Inline Diff:** Live Review, Inline Compare, and Time Machine are now
  part of the free [Inline Diff for Eclipse](/inline-diff/), which is installed
  with ChangeReview. ChangeReview adds Agent Review for GitHub Copilot.
- **No expiry:** Early Access 2 is free during early access and does not expire.
- **Agent Review preferences:** clearer choice between reviewing agent changes
  in the editor (with Keep, Undo, and Time Machine history) or in the Compare
  Editor.
- **Preferences:** ChangeReview and Inline Diff each have their own top-level
  preference page.
- Light and dark theme support for the Keep / Undo widgets and Time Machine.

## 1.0 Early Access 1

*Oct 26, 2026*

- **Live Review:** review uncommitted changes inline in your text editor.
- **Inline Compare:** switch Eclipse's Compare Editor between side-by-side and inline views.
- **Time Machine:** explore past file versions on a timeline without changing your editor buffer or the file on disk.
- **Agent Review:** detect and track code changes made by AI coding agents - currently limited to the GitHub Copilot for Eclipse plugin
- Consistent green additions and red deletion gaps across all three tools.
- Syntax coloring for all languages, with the editor's theme, font, line numbers, and diff gutter markers.
- A floating navigator for stepping through changes.
