# Eclipse AI Tools by Genuitec

Documentation and community for **Inline Diff for Eclipse** and **ChangeReview**.

| | |
|---|---|
| **Inline Diff for Eclipse** (free) | Review changes inline in the editor you already use: Live Review, Inline Compare, and Time Machine. |
| **ChangeReview** (early access) | Review GitHub Copilot's agent changes before you keep them. Builds on Inline Diff. |

## Documentation

https://genuitec.github.io/eclipse-ai-tools/

- [Inline Diff for Eclipse](https://genuitec.github.io/eclipse-ai-tools/inline-diff/)
- [ChangeReview](https://genuitec.github.io/eclipse-ai-tools/changereview/)

## Community

- **[Discussions](https://github.com/Genuitec/eclipse-ai-tools/discussions)** – questions, ideas, and announcements for both products.
- **[Report a bug](https://github.com/Genuitec/eclipse-ai-tools/issues/new/choose)** – something isn't working as documented.

When you post, say which product you're using and include your Eclipse and
plug-in versions (**Help > About Eclipse IDE > Installation Details**).
